# Publication figures

Generated by `tools/render_publication_figures.R`. Each figure is written
as both `.png` (300 DPI raster for README / release notes) and `.pdf`
(vector for publication).

## Regenerate

From the package root:

```bash
Rscript tools/render_publication_figures.R           # all six figures
Rscript tools/render_publication_figures.R f4        # one figure
```

If a data artifact is missing, the loader invokes the matching runner
once (`run_head_to_head_benchmark.R`, `cpp_speedup_bench.R`,
`run_multitrait_validation_grid.R`). Small fixture sizes are used by
default; override via `NG_HEAD_TO_HEAD_*` / `NG_MULTITRAIT_GRID_*`
environment variables and rerun.
